## Aspect-Based Sentiment Analysis for Medical Tourism
An Aspect-Based Sentiment Analysis (ABSA) project developed to analyze Indonesian public sentiment toward medical tourism across six aspects: service, cost, accessibility, facilities, diagnosis quality, and general.
```
The project applies SetFit-based few-shot learning to classify sentiment from 2,671 labeled aspect-sentiment pairs collected from Twitter/X, YouTube, and TikTok.
```

### Objectives
```
Analyze public sentiment toward medical tourism across different service-related aspects.
Develop aspect-specific sentiment classification models using few-shot learning.
Evaluate model performance for each aspect.
```
